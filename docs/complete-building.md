# 完整建筑构件清单（UniFormat 2010 / IFC 对照）

> 依据：BIMForum **LOD Specification**（按 CSI UniFormat 2010 组织，业界通用的"建筑系统清单"）＋ buildingSMART IFC 实体分类。
> 本文件是"该有的都有"的验收台账：每行标注当前管线是 **已生成 / 简化 / 缺失**。

## 0. 当前产物形态

- 全部为 **LOD 200/250 几何体量**：墙/板/柱/梁用原生对象，其余用 `box` 实体（可带绕 Z 旋转角）。
- 不代表可施工：无材料分层、无节点、无族参数、无机电系统连接关系。

## 2. 距 LOD 300 的差距（按优先级）

1. ~~语义层~~：**已实现** —— request 带 `levels`/`rooms`/`grids`，Revit 侧建 `Level`（逐层）、`Room`（带名称/编号）、`Grid`（轴号）。
2. **楼梯/门窗族**：现在都是 box/薄板，缺梯段参数、门扇开启方向、窗型。
3. **构造层**：屋面防水/保温、墙体内外饰面、楼面做法 —— 需要多图层实体或材质。
4. **机电系统**：水平管线（给排水/消防喷淋/风管/桥架）与设备（水泵、空调机组、配电箱），需要管线路径生成与避让规则。
5. **出图**：✅ 平面/立面/剖面视图 + 门窗表 + A1 图框标题栏套图（`--sheets`）；待补：房间面积表进图纸、精确消隐立面。
6. **场地**：道路、绿化、停车、围墙大门。

```powershell
python brief_to_cad.py --intent intent.json --plan --request req.json --dwg out.dwg
```

A-MEP-ELEC / A-MEP-HVAC / A-SITE / A-STAIR / A-GRID`。
