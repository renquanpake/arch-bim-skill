# PDF 矢量 → CAD → Revit 全链路（A02 实战沉淀）

> 定位：`SKILL.md` §1 执行流程的展开细节。**拿到甲方 PDF 图纸要转成可编辑 BIM 模型时，按本文走。**
> 来源：A02 住宅楼 B1+1F（图纸 `D:\A02_BIM_归档\00_原始图纸\图纸 住宅(1).pdf`，16MB，A2 幅面 1:100）。
> 配套文档：`revit-headless-playbook.md`（怎么无头启动 Revit）、`revit-precision-playbook.md`（建模精度细节）。

---

## 0. 全链路一张图

```
甲方 PDF（矢量）
   │  ① 矢量提取 + 比例换算（1pt = 24.948mm）
   ▼
中间 DXF（保留原图层，坐标可能未对齐）
   │  ② 按图层提墙线 + 双线配对成墙中线 + 平移对齐
   ▼
结构坐标 JSON（墙线端点，mm，已对齐到项目原点）
   │  ③ 无头 Revit 插件按坐标建墙 / 开洞 / 建轴网
   ▼
RVT（墙+洞口+轴网+视图）
   │  ④ 导出 PNG 与 CAD 叠图 + 数值对账
   ▼
验收报告（偏差中位数 / 覆盖率 / 缺口清单）
```

**关键判断**：这条链的价值不在"能转"，在**可量化验收**。每阶段都必须产出可对账的数字，禁止"看着像"就收货。

## 1. 阶段①：PDF 矢量 → DXF

### 1.1 前提判定：先确认 PDF 有矢量层

```python
import fitz  # pymupdf
doc = fitz.open(pdf_path)
page = doc[3]                       # A02 首层平面图在第 4 页（0-based 3）
paths = page.get_drawings()         # 有返回值 = 有矢量
print(len(paths), page.rect)        # 实测：上万条
```

- 有 `get_drawings()` 返回 → 走本文路线；
- 返回空 / 只有位图 → 是扫描件，走 OCR/描图路线，**本文不适用**，且精度承诺要下调。

### 1.2 比例换算（最容易错的一步）

A2 幅面 1:100 图纸实测：**1 pt = 24.948 mm**。

```python
K = 24.948          # pt → mm
x_mm = (x_pt - origin_x) * K
y_mm = (y_pt - origin_y) * K
```

三个要点：

1. **先减原点再乘 K**，顺序反了整个模型会偏出几十米；
2. K 不是猜的——用图上已知尺寸链反算校验：A02 的 X 向轴距合计 41200mm、Y 向 13300mm，对不上就说明 K 或原点错了；
3. 不同幅面/比例 K 不同，**每张图单独标定**，禁止沿用上一张。

### 1.3 图层必须保留

转 DXF 时按 PDF 的线宽/颜色分层，A02 实测图层语义：

| 图层 | 内容 | 用途 |
|---|---|---|
| `A-VEC-035` | **墙双线** | 主力提取层，建模全靠它 |
| `A-VEC-050` | 尺寸标注 | 反推尺寸链、校验 K |
| `A-VEC-025` | 文字 | 房间名、轴号 |
| `A-VEC-018` | 家具 | **不建模**，仅作参考 |
| `A-VEC-000` | 轴线 | 杂乱，需按规则过滤重建 |
| `A-FILL` | HATCH 填充 | 楼板/材料区分 |

> 教训：把所有线合并成一层再处理，等于自废武功——双线配对、轴线识别全部失效。

## 2. 阶段②：DXF → 结构坐标 JSON

### 2.1 只提墙双线，不做全图配对

从 `A-VEC-035` 提取所有线段 → 按"平行 + 间距≈标准墙厚"配对 → 取中点连线作为墙中线。

实测 A02：**-1F 得 214 面墙，1F 得 223 面墙**。

### 2.2 平移对齐（每个 DXF 单独做）

不同页导出的 DXF 原点不一致，必须对齐到同一坐标原点：

```python
# A02 page04.dxf（1F）实测平移量
DX, DY = -16040.4, 36342.0
```

对齐量怎么来：挑 3 处**唯一的几何特征**（如外墙角点），在新旧坐标下各取一次，差值即平移量；三处互校，不一致说明抓错点了。

### 2.3 输出格式（给 Revit 插件吃的）

```json
{
  "walls": [
    {"x1": 0, "y1": 0, "x2": 3600, "y2": 0, "thickness": 200, "level": "1F"}
  ]
}
```

字段约定：`mm` 单位、右手系、`thickness` 用实测双线间距而非查表值（图纸上 200 墙可能画出 198）。

### 2.4 房间 / 洞口

- **洞口（门窗）**：从墙中线两侧的短线段对 + 洞口弧线识别；A02 实测 1F 得 **40 个洞口**（window 30 / door 9 / hole 1）；
- 洞口只建 **Opening（纯洞口）**，不建门窗族——CAD 平面图给不出族类型和开启方向，硬建就是编造。

## 3. 阶段③：CAD/DXF 进 Revit

### 3.1 链接，不是导入（用户红线，反复强调过）

| 方式 | API | 何时用 |
|---|---|---|
| **链接** | `DWGImportOptions` + link 语义 | **默认**。可在"管理链接"里改路径、卸载、重载；不污染模型库 |
| 导入 | `ImportInstance` | 仅一次性底图参考，导入后难管理 |

> 原话纠正：「你要去 revit 里找链接，revit 不是导入」。以后一律链接。

### 3.2 链接的副作用：撑大视图包围盒

A02 踩过一次真实的坑：

| 视图 | 删链接前导出尺寸 | 删链接后 |
|---|---|---|
| `-1F` 平面 | 4000×2825（内容被压成一条） | 4000×1466 |
| `1F` 平面 | 4000×1473 | 4000×1473 |

原因：残留的 `03_-1F_对齐.dxf` 链接把视图包围盒撑到 **84080×59387 mm**，导出按包围盒等比缩放，主体就被压扁了。

**处理规范**：
1. 出图前先查链接：遍历 `ImportInstance` 判断是否 linked；
2. 要删链接**先做副本再删**（用户要求："做个副本然后删了，这样就随便了"）；
3. 删完必须重量包围盒复验，尺寸差异应 <1%（A02 复验 1466 vs 1473，差 0.5%，正常）。

### 3.3 墙体几何：用坐标重建，不要用"拾取线"

- `Wall.Create` 按 JSON 端点 + 厚度直接建 → 坐标可控、可回读、可对账（A02 主力做法）；
- `ImportInstance` 拾取线建模 → 依赖人工点选，无头环境不可用，且无法批量复现。
- **禁止 rebuild**：Revit 的 `Document.Rebuild` 类操作会丢参数，重建后编号/类型全乱。

## 4. 阶段④：精度验证（本链路的核心，不是可选项）

### 4.1 四条路线实测对比（A02 真数据）

| 路线 | 方法 | 实测中位偏差 | 结论 |
|---|---|---|---|
| PDF 提取 + ICP 配准 | 点云配准 | **42.5mm** | **淘汰**：残差大且覆盖率低 |
| **DXF `A-VEC-035` 直提双线配对** | 平行线配对 | **0.34mm** | **采纳**——"百分之百准"路线 |
| 1F 边线 → CAD 线匹配 | 边线最近邻 | **0.74mm** | 可用（比 -1F 略差，因 1F 有凸出体量） |
| 洞口中心 API 回读 | 回读 vs 设计值 | **0.05mm** | 通过 |

**选型原则**：能直提就不要配准。ICP 看起来高级，但 PDF 提取的点云本身就带误差，配准只是在拟合噪声。

### 4.2 五种验证手段，按需组合

| 手段 | 做法 | 判据 |
|---|---|---|
| **叠加图** | Revit 导出 PNG 与 CAD 线稿半透明叠加 | 肉眼可见错位 > 2mm 即不合格 |
| **数值对账** | `scripts/verify_geometry.py` 逐墙最近邻距离 | 中位数 < 1mm，P95 < 5mm |
| **缺口核查** | shapely 墙体并集 + 缓冲区 | 见 4.3 |
| **包围盒复验** | 导出前后尺寸比对 | 差异 < 1% |
| **统计对账** | 墙数/洞口数/轴网数 vs CAD 识别数 | 数量必须一致，差一个都要说明 |

### 4.3 缺口核查（A02 实用招）

用户只关心"较大的缺"，小缺忽略。做法：

```python
from shapely.ops import unary_union
buffered = unary_union([w.buffer(tol) for w in walls])   # 墙并集缓冲
gaps = boundary.difference(buffered)                      # 边界减墙 = 缺口
for g in gaps:
    if g.length > 1000:                                   # 阈值 1m，可调
        report(g)
```

A02 实测结果：南墙无缺口；东/西墙只在 Y>11740 处外错台 1.0m（体量变化，非缺）；北墙 `y=11637` 有 4 段空白，其中 **2 段真断口各 3.75m**（X 13.64–17.39m、21.19–24.94m），另 2 段为凸出体量开口。

> 关键：**先约好阈值再报**。不设阈值会把构造缝、错台全报成"缺失"，用户直接不看了。

### 4.4 轴网必须回 PDF 核对

不要凭模型里的墙反推轴网——容易漏。A02 从 PDF 第 4 页直接提轴号：

- X 向 **1~25 连续无跳号**，轴距 900/2600/3150/650/1650/1350/1350/1650/650/3150/2600/900（镜像），合计 **41200mm**；
- Y 向 **A,B,C,D,E,F,G,H,J（跳 I）**，轴距 1600/2900/1100/1900/800/1100/1300/2600，合计 **13300mm**。

尺寸链必须闭合，闭合不上就是提取错了。

## 5. 五个高频坑（都是真踩过的）

| # | 坑 | 现象 | 解法 |
|---|---|---|---|
| 1 | K 值沿用上一张图 | 模型整体缩放错 | 每图反算尺寸链校验 |
| 2 | 原点顺序错（先乘后减） | 模型偏出几十米 | 先减原点再乘 K |
| 3 | 全图线混一层 | 双线配不上、轴线乱 | 保留 PDF 图层语义 |
| 4 | 残留 CAD 链接撑大包围盒 | 导出图被压成一条 | 出图前清链接（先备份） |
| 5 | 拿墙反推轴网 | 漏轴、跳号 | 轴网回 PDF 提，尺寸链闭合校验 |

补充：手绘 PDF 常无文字层，尺寸只能靠线段间距/轴网气泡反推，此时在 `truth.json` 里标 `derived: true`，**别把反推值冒充设计值**。

## 6. 交付自检

```
[ ] 1. PDF 确认有矢量层，K 值已用尺寸链反算校验
[ ] 2. DXF 保留原图层，墙只从 A-VEC-035 提

[ ] 6. 轴网从 PDF 提，X/Y 尺寸链闭合
[ ] 7. 出图前清残留链接（先备份），包围盒复验差异 <1%
[ ] 8. 精度四数齐：墙中线中位偏差、洞口回读偏差、缺口清单、统计对账
```
