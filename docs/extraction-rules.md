# 图纸数字化·非墙线黑名单与判例

来源：2026-10 住宅施工图（19 页 A0）矢量提取翻车复盘。子 agent 数字比对打分 42/100，
以下签名规则可拦截其中全部误提取。

## 判例（本次实际翻车点）

| 误提取 | 几何签名 | 正确处置 |
|---|---|---|
| 楼梯踏步"梳子" | ≥6 条平行短线等距排列，间距 250-300mm，整簇宽=梯段宽(1100-1600) | 整簇剔除，按楼梯详图另建 box 踏步 |
| 坡道/雨棚线 | 建筑轮廓外、单线、无配对第二面线、常为斜线或折线 | 剔除 |
| 轴线尺寸刻度 | 垂直于尺寸线的 45° 短斜线(100-250mm)，等间距出现在尺寸链上 | 剔除 |
| 标注引线 | 斜线一端触文字团 | 剔除 |
| 填充/剖面线 | 45° 等距平行线阵，间距 <100mm | 剔除 |
| 窗线/玻璃线 | 落在墙带内部、平行于墙、长度≈洞口宽 | 是洞口证据，不是墙 |
| 构造柱 | 100-240mm 小方块，四边闭合 | 转 column，不是墙 |

## 轴对齐审查（准入规则）

墙面坐标 v 与轴线集 A、半厚 t/2 的合法关系：`min(|v-a|, ||v-a|-t/2|) ≤ 100mm`。
超差 → 嫌疑墙，不进模型。原点/比例标定：气泡轴距序列 vs 尺寸链读数逐项比对，容差 ±50mm；
轴 1 由轴号文字确认（本次山墙偏 1.5-1.6m 即原点气泡选错轴）。

## 洞口对账

`|实测宽 - 编号标称宽| ≤ 100mm` 才收录；门/窗定性优先级：
1. 编号首字母（C=窗 M/FM/DYM/YTM/TLM/HM=门 BY=百叶窗）
2. 门弧曲线（半径≈门宽，圆心在洞口端点）
3. 断口宽度（≥1800 多为门/门联窗）
禁止仅凭断口形状猜定性（本次 FM甲1823 门被判成窗、MLC3828 宽度只剩 1/3 均源于此）。
