# 制图标准与标注规范落地清单（drawing-standards）

> 用途：为施工图套图管线（`sheets.py` + `brief_to_cad.py`）补「标高符号、轴号圆圈、房间标签、指北针、门窗编号、图框线型、比例尺、会签栏」的落地依据与几何配方。
> 依据：GB/T 50001-2017《房屋建筑制图统一标准》为主，辅以 GB/T 14689-2008《技术制图 复制图的折叠布局/图框与标题栏相关》、GB/T 10609.1-2008《技术制图 标题栏》、GB/T 14691-1993《技术制图 字体》、GB/T 50104-2010《总制图标准》、GB/T 50353-2013《建筑工程建筑面积计算规范》（面积口径）。
> ⚠️ 本文数字系编写时按现行标准通行条文整理；个别尺寸标准只给区间或属行业惯例（文中已标注「惯例」）。正式出图前以标准原文核对一遍。
> 只读调研产物，不改代码。配套阅读：`docs/cad-detailing-guide.md`（§2 标注规范摘录、§6 出图组织）。

## 1. GB/T 50001-2017 关键要点（按出图动作组织）

### 1.1 图幅与图框（含 GB/T 14689）

- 幅面（横放，mm）：A0 1189×841、A1 841×594、A2 594×420、A3 420×297、A4 297×210。可加长（长边按 √2 倍数）。
- 留边：装订侧 25mm（A0~A2）/ 10mm（A3、A4）；其余三边 10mm（A0~A2）/ 5mm（A3、A4）。
- **双框线**：外框线=细实线（沿图纸边缘）；内框线（图界）=与图面轮廓同宽的**粗实线**。
- 标题栏位置：右下角，压内框线；会签栏在标题栏左侧（或上侧，竖排图纸时）。
- 多张同幅图纸：首张画完整图框，后续可用简化框线+编号（惯例）。

### 1.2 线型与线宽组

线宽系列（R5，mm）：0.18 / 0.25 / 0.35 / 0.5 / 0.7 / 1.0 / 1.4 / 2.0。
基本图按三组（以 b=0.7 为例）：**粗 b=0.7、中 0.5b≈0.35、细 0.25b≈0.18**（1:100 出图常用；大样按比例选组）。

| 线型 | 宽 | 用途（建筑图） |
|------|----|----------------|
| 粗实线 | b | 剖面被切断的墙/楼板轮廓、图框内框线、大样钢筋混凝土断面、剖切位置线、图名下划线 |
| 中实线 | 0.5b | 可见轮廓（未剖到的墙、门窗）、指北针指北针杆 |
| 细实线 | 0.25b | 尺寸线、尺寸界线、标高符号、引线、填充线、门扇开启线、图例线 |
| 虚线（中/细） | — | 不可见轮廓、拟建/预留部分 |
| 单点划线 | 细 | 轴线、对称线 |
| 双点划线 | 细 | 相邻未画部分轮廓、道路中心线（总图） |
| 波浪线/折断线 | 细 | 断开界线、范围打断 |

- 点划线线段：长段约 10~20mm、短段 2~3mm、间隙 1~3mm（同图统一）——本管线用短折线多段模拟（§5.2）。
- 线宽在 CAD 里两种实现：对象线宽 或 **打印样式 CTB 按图层映射**。本项目只能走 CTB（§7 映射表）。

### 1.3 文字（含 GB/T 14691）

- 中文：长仿宋体（或仿宋），简化字；数字字母：等线/ISO 3098 简单体。
- 字高系列（mm）：1.8 / 2.5 / 3.5 / 5 / 7 / 10 / 14 / 20。**图面最小字高 2.5**；常用：房间名/标高数字 3.5，轴线编号 5，图名 7~10，图纸封面字更大。
- 图名注法：图名水平书写于图下方，**名下画粗实线（b），线长=字宽**；比例注写于图名右侧或下划线右端，字高比图名小 1~2 号（惯例）。
- 字头方向：垂直尺寸的数字字头朝左；水平尺寸字头向上；尽量不把尺寸数字写在尺寸线下方（惯例）。

### 1.4 标高（重点）

- 数字：米，**三位小数**（如 `3.000`、`-0.010`）；总图可两位。负值带「−」；±0.000 写作 `±0.000`。
- **符号形式（四种，均为细实线绘制，三角形为等腰直角、尖角 45°）**：
  1. **一般标高**：直角顶点指向标高位置（下/上），斜边（水平顶边）向一侧延长成横线，数字注于横线上方。符号整体高度与字高相称：字高 h 时三角形高≈h、顶边宽≈2h、横线长出顶边≈3~4h（标准给比例示意，具体取值见 §5.1 配方）。
  2. **45° 斜置形式**：空间窄（图上密集处）时，符号整体旋转 45°，数字仍写在横线上方（横线的另一延长方向）。
  3. ** finishes/已完成表面（断面、剖面上注写）**：三角形内**涂黑**（实心）。本管线无填充→用套叠三角或密折线模拟（§5.1）。
  4. **最高一层平面上的标高符号**：**双线三角形**（两层细实线三角）。
- 引出标注：标高数字过多/位置偏时，可画水平引出线（细实线），符号+数字置于线端（惯例）。
- 每层平面：至少注本层地面标高（楼梯间、外廊、变标高处加注）；立面：室外地坪、各层楼面、檐口/女儿墙顶；剖面：同立面并加门窗洞口上下标高（惯例三组）。

### 1.5 尺寸标注

- 组成：尺寸线（细实线，平行被注线段）+ 尺寸界线（细实线，垂直引出，超出尺寸线 2~3mm）+ 起止符号 + 数字。
- 起止符号：建筑图用 **45° 短斜线（中粗，长 2~3mm，斜向统一右上方）**；半径/直径/坡度/引线用箭头（2~3mm 实心）；点（φ1~1.5mm 圆点）用于角度或空间窄处。
- 排布：平行尺寸线由近及远「细部→定位→总尺寸」，互不相交；多层外围**三道尺寸**（门窗洞口及定位、轴间距、总长）为立面/平面惯例。
- 单位：尺寸数字以 **mm** 计（标高、面积、总图以 m/㎡ 除外），不写单位符号。

### 1.6 剖切符号与剖面图

- 剖切符号三部分（画于平面，细部见 §5.6 配方）：
  1. **剖切位置线**：粗实线（b），长 6~10mm，贯穿被剖构件；
  2. **投影方向线**：与剖切线端部垂直，中实线（0.5b），长 3~5mm（惯例取剖切线一半宽），不画箭头；
  3. **编号**：阿拉伯数字顺序 1、2、3…，字高比图面文字大一号（≈5mm），注写在投影方向线的末端一侧；剖切线转折（阶梯剖）转折处画粗直角并同注编号。
- 剖面图下方图名：`1-1 剖面  比例`，与平面剖切符号编号一致；被剖切到的墙楼板用粗线 b，可见未剖部分中/细线；剖面上的标高见 §1.4。
- 多层建筑：每层被剖到都应有编号贯通；立面指向（哪个立面）用「南/东/北/西立面」命名，或 ①~④ 编号（顺时针，主入口面起，惯例）。

### 1.7 索引符号与详图符号

| 符号 | 画法 | 内容 |
|------|------|------|
| 索引符号（指向详图） | **细实线圆 φ10**，中间水平直径线 | 上半=详图编号（阿拉伯），下半=详图所在图纸编号；详图在同张图纸时下半画「—」 |
| 详图符号（详图旁） | **粗实线圆 φ10（b）** | 上半=详图编号；下半=所在图纸号（同图则只写编号/下半画「—」） |
| 视图部位索引 | 细实线圆 φ8 + 引出 | 用于立面/剖面在平面上的位置圈注（惯例，配合 §1.6） |
| 剖视方向 | 索引圆内加方向线 | 详图剖切方向与母图一致时标注（惯例） |

本管线小项目实用做法：平面门窗洞口旁注「详图 1/图集页」用索引圆；节点大样出 `S-5xx` 系列图纸（与 `cad-detailing-guide.md` §6 图号体系一致）。

### 1.8 指北针与风向频率（含 GB/T 50104 总图）

- 圆：**细实线，直径 24mm**（小图幅可缩至 20mm，惯例）。
- 指北针杆： slender 等腰三角形（一头尖细指北，常用粗实线勾勒或半涂黑），**针尖出圆外约 3~5mm**；针尾可加细杆。
- 「北」或「N」字注于针尖上方（长仿宋，字高 5~7mm）。
- 出现位置：总平面图、各层平面（方位图）、屋顶平面必须有；立面/剖面可不注。图面转正北时指北针随之旋转（正北=真北；项目用「上北下南」时仍画，防歧义）。

### 1.9 比例（GB/T 50001 推荐比例系列）

- 常用：平面/立面/剖面 1:50、1:100、1:200；大样 1:1、1:2、1:5、1:10、1:20、1:50；总图 1:500、1:1000、1:2000、1:5000。
- 注写：图名右侧「比例 1:100」（字高比图名小 1~2 号）；一张图多个比例时在图名下注「比例见各分图名」或逐个图名带比例。
- 线段式比例尺（graphic scale）：非规范要求，可不画；**文字比例必须有**（现在只有图纸标题栏里有，图名旁缺）。

### 1.10 楼层、性能与房间标注

- 楼层注写：「一层 / 二层…」或「L1/F1…」+ 该层标高并列（如 `三层 12.000`）；楼梯平台分「休息平台标高 / 梯段平台标高」注写。
- 房间标签惯例三行：**名称（3.5~5mm）/ 面积（数字 3.5mm，㎡ 两位小数）/ 标高（符号+数字）**；面积口径按 GB/T 50353 或注明「净面积」——本管线 `schedules.py` 已按 outline 净轮廓计算，图面注明口径「使用面积」。
- 门窗编号（图面↔门窗表索引）：
  - 格式：类别代号+四位数字，前两位=洞宽分米码、后两位=洞高分米码：`M0921`=门 900×2100，`C1513`=窗 1500×1300；
  - 前缀：`FM甲/FM乙/FM丙` 防火门（甲级…），`FC` 防火窗，`LM` 落地门/连板门（惯例各异，图例说明即可）；
  - 注写位置：靠洞口、墙体外侧或门洞断口处，字高 3.5mm，水平书写；同型号多樘时按「M0921①②…」或表统计樘数。

### 1.11 图框标题栏字段（会签栏，GB/T 10609.1 + 行业惯例）

- 标题栏（右下角）必备字段：**工程名称、设计单位名称、工程编号、图名、图号（册编号+详图号）、比例、日期、设计阶段（方案/初设/施工图）、签字（设计/校对/审核/审定 + 专业负责人）**。机械标准栏 180×56mm；建筑院标多为 240 宽，按幅面缩放（惯例）。
- 会签栏（标题栏左侧，跨专业签字）：纵向 5~8 列，列宽 ≈14mm；每列上下两格：**上=专业/职责名（审定、审核、校对、建筑、结构、给排水、暖通、电气），下=签字+日期**。出图责任四方签字（设计/校对/审核/审定）是施工图审查要点，方案阶段可省。
- 当前管线的图签（`sheets.py:72-87`）：工程名/图名/阶段 | 图号/比例/日期，**缺：设计单位、工程编号、四方签字、会签栏**；且为单线外框、无内框线/装订边区分。

## 2. 管线现状逐条对照

- **纸面坐标**：`sheets.py` 全部元素以「米」表示纸面（A1=0.841×0.594），即 **纸面 1mm = 0.001「米单位」**；标题栏字高 0.006=6mm。

## 3. 缺失项优先级（成本 × 出图价值）

```
价值高 ┃ ①标高符号        ②轴号圆      ③指北针       ④门窗编号      ⑤房间三行标签
       ┃ ⑥剖切符号        ⑦图名下划线+比例
       ┃ ⑧表格进图引擎    ⑨会签栏
       ┃ ⑩索引/详图圆     ⑪门扇弧+窗三线   ⑫图例    ⑬修订云线
       ┃ ⑭真线型线宽      ⑮三道尺寸体系    ⑯线段比例尺
       ┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━ 低成本 ──────→ 高成本
```

| 排序 | 项 | 成本 | 价值 | 理由 |
|---|---|---|---|---|
| 1 | 标高符号 | 低（~30 行） | ★★★★★ | 平/立/剖面缺一不可；审查硬指标；纯 polyline+text |

## 4. 两套坐标的换算规则（写 helper 前先定死）

| 空间 | 单位约定 | 纸面 mm→数值 | 适用函数 |
|---|---|---|---|
| 纸面（sheets.py 内） | 米=纸面（A1 宽 0.841） | `mm × 0.001` | 图框、标题栏、指北针、表格、会签栏、CAP |
| 模型（build_plan_elements 等） | 米=真实尺寸 | `mm × 0.001 × scale`（1:100→×0.1） | 标高、轴号、房间标签、门窗编号、剖切符号（这些要跟着视图被 `_fit` 缩放） |

> 推荐：所有标注 helper 写成**纸面 mm 参数**，内部一个 `PAPER = 0.001`，模型版调用时传 `mm × scale / 1000`。现有最小字高保护 `max(0.0025, …)`（`sheets.py:65`）=2.5mm，正好是 §1.3 底线，新增项字高一律 ≥0.003（纸面）。

## 5. 几何构造配方（直接照抄成函数）

以下所有 `points` 均为 `[x, y]`；`_rect/_line/_text` 用 `sheets.py:21-34` 的既有工厂；`(cx, cy)` 为基准点。**给的是纸面坐标（A1 上的米值），模型空间乘 scale/100 套用。**

### 5.1 标高符号 `elev_symbol(x, y, value, topmost=False, filled=False)`

三角形高 3mm、顶边宽 6mm，横线自左顶点起向右总长 17mm，数字高 3.5mm 注于横线上方：

```python
h = 0.003                                   # 三角形高
pts = [[x, y], [x - h, y + h], [x + h, y + h]]
els = [{"type": "polyline2d", "name": "ELEV-T", "closed": True, "points": pts, "layer": "A-ELEV"}]
els.append(_line(x - h, y + h, x + 0.014, y + h, "ELEV-L", "A-ELEV"))          # 横线（含顶边）
s = ("-0.010" if v < 0 else ("%+.3f" % v)).replace("+", "")                    # 3.000 / -0.010
if abs(v) < 1e-6: s = "±0.000"
els.append(_text(x + 0.0015, y + h + 0.0008, s, "ELEV-N", 0.0035, layer="A-ELEV"))
```

- **最高层双线**：再加内缩三角 `pts2 = [[x, y+0.0011], [x-0.0019, y+h], [x+0.0019, y+h]]`，closed=True，同层。
- **断面涂黑（实心）**：polyline 无填充→三角形内画 3 条平行短线模拟（y+h×0.25/0.5/0.75 处，宽度按边斜率收缩：`[x-t*(h-(y_off)), …]`，t=余切 45°=y_off/h 比例），或直接接受「双线描边+数字」降级。
- **45° 斜置**：把上述全部点绕 `(x, y)` 旋转 -45°（`cos/sin` 手算，text 的 `rotation` 给 `-math.pi/4`）；空间窄处用。
- 注写位置：平面=外墙外侧/楼梯间/房间角落；剖面=每层楼面、门窗上下沿、檐口。模型 1:100 时全部 ×100（三角 0.3m、字 0.35m）。

### 5.2 轴号圆 `axis_tag(cx, cy, label)` + 点划轴线 `dash_dot_line(p0, p1)`

```python
def _poly_circle(cx, cy, r, n=16, name="AXIS-C", layer="A-AXIS"):
    pts = [[round(cx + r * math.cos(2 * math.pi * i / n), 5),
            round(cy + r * math.sin(2 * math.pi * i / n), 5)] for i in range(n)]
    return {"type": "polyline2d", "name": name, "closed": True, "points": pts, "layer": layer}
```

- 轴号圆：`r = 0.004`（φ8mm），编号字高 5mm，居中偏移：`_text(cx - len(label)*0.0015, cy - 0.0025, label, ...)`。
- 替换点：`build_grid_el`（`brief_to_cad.py:538-562`）文字改在轴端外侧 `ext + 0.3 + r` 处加 `_poly_circle`（模型 r=0.4m），数字进圆心；字母编号**跳过 I、O、Z**（易混 1/0/2，通行规定）：`letters = [c for c in "ABCDEFGHJKLMNPQRSTUVWXY"]`。
- 点划线模拟（长划12/空3/短点2/空3，mm）：

```python
def dash_dot_line(x0, y0, x1, y1, name, layer="A-AXIS"):
    L = math.hypot(x1 - x0, y1 - y0); ux, uy = (x1 - x0) / L, (y1 - y0) / L
    pat, els, t = [(0.012, 1), (0.003, 0), (0.002, 1), (0.003, 0)], [], 0.0
    while t < L:
        seg, draw = pattern_cycle_next(pat)          # 取一段长划/空隙
        if draw:
            els.append(_line(x0 + ux * t, y0 + uy * t,
                             x0 + ux * min(t + seg, L), y0 + uy * min(t + seg, L), name, layer))
        t += seg
    return els
```

> 每段是独立 polyline2d（2 点），段数=轴长/17mm，A1 图上一根轴 ~50 段，元素量可控。嫌碎可只对**轴网端部出圈部分**用点划，中部保持 A-GRID 实线（降级方案，先解决"有没有圈"）。

### 5.6 剖切符号 `section_mark(p0, p1, num, side=+1)`

模型空间（1:100：剖切线长=纸面 6~10mm→0.6~1.0m；用「粗矩形描边」模拟粗线）：

```python
def _thick_line(x0, y0, x1, y1, w=0.001, name="TL", layer="A-SHEET"):
    # 用 0.7mm 宽的细长矩形（closed polyline）模拟粗实线；纸面坐标
    dx, dy = x1 - x0, y1 - y0; L = math.hypot(dx, dy) or 1e-9
    nx, ny = -dy / L * w / 2, dx / L * w / 2
    return {"type": "polyline2d", "name": name, "closed": True,
            "points": [[x0 + nx, y0 + ny], [x1 + nx, y1 + ny],
                       [x1 - nx, y1 - ny], [x0 - nx, y0 - ny]], "layer": layer}
```

剖切符号三件套（沿剖切线 u=(ux,uy)，法线 n 指投影方向）：


## 6. 门窗表/面积表进图面（`_table` 引擎 + 布局）

数据现成：`build_schedule_csv`（门/窗聚合）、`schedules.build_room_schedule`（房间+层小计）、`build_quantity_takeoff`（快估）。缺一个 CSV→图面表格的引擎。**纸面坐标画，不随视图缩放。**

### 6.1 引擎（约 40 行）

```python
def _table(x0, y_top, rows, widths, rh=0.008, hh=0.0035, bh=0.003, layer="A-TBL"):
    """rows: [[cell,…],…] 第一行为表头；widths: 各列宽(纸面m)；自 y_top 向下生长。"""
    els, W = [], sum(widths)
    n = len(rows)
    for i in range(n + 1):                                   # 横线 n+1 条
        els.append(_line(x0, y_top - i * rh, x0 + W, y_top - i * rh, "TBL-H%d" % i, layer))
    xs = 0
    for j, w in enumerate(widths + [0]):                     # 竖线
        if j < len(widths):
            els.append(_line(x0 + xs, y_top, x0 + xs, y_top - n * rh, "TBL-V%d" % j, layer))
        xs += w
    els.append(_line(x0 + W, y_top, x0 + W, y_top - n * rh, "TBL-VR", layer))
    for i, row in enumerate(rows):
        xs = 0
        for j, cell in enumerate(row):
            h = hh if i == 0 else bh
            els.append(_text(x0 + xs + 0.0012, y_top - (i + 0.62) * rh, str(cell),
                             "TBL-%d-%d" % (i, j), h, layer=layer))
            xs += widths[j]
    return els
```

解析 CSV 用 `csv.reader`（stdlib，与 schedules.py 一致），首行即表头。

| 房间表（`ROOM_HEADER` 5 列） | 层号/编号/名称/面积/周长 | 14/18/46/28/24 | 130 |

## 7. 图层与 CTB 线宽映射（给打印侧，不动代码）

| A-TAG | 门窗编号 | 0.25 | — |
| A-ROOM | 房间标签 | 0.25 | — |

4. 出图自查：跑 `--sheets --sheet-size A1 --sheet-scale 100`，打印/导出 PDF 后量：标高字高≥2.5、轴号圈φ8、指北针φ24、表行高 8mm 都在纸面命中；对照 §2 表勾掉对应 ❌。
5. 第二梯队：`_table` 引擎进图（§6）→ 会签栏（§1.11）→ 索引符号（§5.8）→ 门扇弧/窗三线 → 图例 → 修订云线（绑 `--check`）。

**验收口径**：一张 A1 套图打印出来，让没参与项目的人认出「这是标高、这是轴号、这是指北针、门窗号和表对得上」——过了这条线，标注包 v1 即达标。

## 附：标准边界与已知偏差（诚实清单）

- 本管线是「纸面 1:1 布图」模型（元素按 /scale 缩进图框），符合出图结果，但 DWG 里模型空间 ≠ 1 单位 1mm 的国内常见约定；CTB/布局空间打印时注意换算来源（`sheets.py` 头部注释已声明）。
- 剖切符号的「方向线线宽/长度」GB/T 50001 给的是与剖切线的比例关系，具体 mm 值各教材略有出入，配方取中值；正式版以标准原图核对。
- 指北针 φ24 为大图常用值，标准正文用「宜」；小图 φ20 也可（§5.4 的 R 做成参数）。
- 标题栏/会签栏 GB/T 10609.1 原形是机械栏（180×56），建筑版式为行业标准+各院企业标准，§1.11 给字段清单而非唯一版式。
- 房间面积口径：`schedules.py` 按 outline 净轮廓 shoelace 计算，属「使用面积/净面积」，报审面积需按 GB/T 50353 以轴线/外墙结构面计——图面已建议注口径字样，正式面积表后续需换口径源。
- 轴线编号跳 I/O/Z、±0.000 写法、三道尺寸为通行惯例/相邻标准内容，出图前按当地审图细则复核。
